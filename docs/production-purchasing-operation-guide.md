# 生产采购计划操作文档

## 1. 使用顺序

建议按这个顺序使用：

```text
维护商品 -> 维护供应商 -> 维护成品配方 -> 维护供货规则 -> 查看生产建议 -> 生成采购单 -> 到货确认入库
```

## 2. 维护商品

进入商品管理，先把商品类型分清楚：

- 粽子类商品选择 `成品`。
- 糯米、豆沙馅、猪肉、粽叶、咸蛋黄等选择 `原材料`。

成品需要填写库存预警数量。系统会用这个数量判断是否需要生产。

原材料也可以填写库存预警数量，但智能采购主要按成品生产缺口倒推，不再单纯按原材料预警线采购。

## 3. 维护供应商

进入采购页面，点击“新增供应商”。当前系统的供应商供货规则已经可用于智能采购建议和生产建议，但建议你同时维护默认单价、起订量、采购倍数和交期，方便后续采购建议更准确。

建议填写：

- 供应商名称
- 联系人
- 电话
- 地址
- 备注

供应商只是资料库，真正用于采购建议还需要维护“供货规则”。

## 4. 维护成品配方

进入采购页面 `/purchase`，在下方“生产配置”区域查看和维护“配方详情”。

每次添加一条明细：

```text
成品 + 原材料 + 单位用量 + 损耗率
```

示例：

```text
豆沙粽 + 糯米 + 0.0200 + 0.0300
豆沙粽 + 豆沙馅 + 0.0100 + 0.0300
豆沙粽 + 粽叶 + 0.0040 + 0.0200
```

单位用量的含义是“生产 1 个成品需要多少当前库存单位的原材料”。

如果原材料库存单位是“袋”，那 `0.0200` 就表示生产 1 个粽子消耗 `0.0200` 袋。

配方详情支持：

- 搜索成品编号、成品名称、原材料编号、原材料名称。
- 按成品筛选。
- 分页查看。
- 编辑或删除单条配方明细。

如果商品很多，可以先在“添加配方”里的成品和原材料搜索框输入编号或名称，再从下拉中选择。

## 5. 维护供货规则

进入采购页面 `/purchase`，在下方“生产配置”区域查看和维护“供货规则详情”。

每个原材料至少建议维护一个默认供应商。

字段说明：

- 默认单价：生成采购单时自动带出。
- 起订量：供应商最少要求采购多少。
- 采购倍数：只能按多少的倍数采购。
- 交期天数：用于计算预计到货日期。

示例：

```text
糯米供应商 + 糯米 + 120 + 起订1 + 倍数1 + 交期3天
```

如果某个原材料没有供货规则，智能采购建议会显示“未绑定供应商”，这时不能直接生成采购单。

## 6. 查看生产建议

采购页面右侧“生产建议”会显示低于预警线的成品。

重点看三项：

- 建议生产多少。
- 当前最多能生产多少。
- 哪些原材料有缺口。

如果“当前最多可生产量”小于“建议生产量”，说明原材料不够，需要先采购。

## 7. 生成采购单

采购页面右侧“智能采购建议”会按供应商分组。

点击“生成采购单”后，系统会自动带出：

- 供应商
- 预计到货日期
- 原材料明细
- 建议采购数量
- 默认采购单价

确认无误后点击“保存采购单”。

保存后采购单状态为：

- 不勾选草稿：待入库。
- 勾选草稿：草稿，暂时不能确认入库。

## 8. 到货确认入库

采购单到货后，在采购单列表点击“确认入库”。

系统会自动完成：

- 增加对应原材料库存。
- 写入库存流水。
- 把采购单状态改为已入库。

已入库采购单不能再修改或取消。

## 9. 常见问题

### 9.1 为什么采购建议为空？

可能原因：

- 成品库存没有低于预警线。
- 成品没有配置配方。
- 原材料库存和待入库采购已经足够覆盖生产需求。

### 9.2 为什么不能采购成品粽子？

当前业务定义中，采购只采购原材料。成品粽子需要通过生产入库，避免采购逻辑和生产逻辑混在一起。

### 9.3 为什么采购建议比缺口多？

系统会按供应商供货规则修正：

- 不低于起订量。
- 向上取整到采购倍数。

例如缺口 17，采购倍数 5，系统建议采购 20。

### 9.4 为什么有“未绑定供应商”？

说明这个原材料缺货，但还没有维护供货规则。先在“供货规则”里绑定供应商，再刷新采购建议。

## 10. 当前推荐日常流程

每天先看首页库存概览，再进入采购页面看生产建议。

如果成品低于预警线：

1. 检查生产建议。
2. 看当前可生产量。
3. 如果原材料不足，按智能采购建议生成采购单。
4. 原材料到货后确认入库。
5. 后续生产单功能上线后，再通过生产单领料并成品入库。
