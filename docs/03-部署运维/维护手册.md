# 维护手册

## 日常查看

查看后端状态：

```bash
systemctl status psi-api
```

查看后端实时日志：

```bash
journalctl -u psi-api -f
```

查看最近 200 行日志：

```bash
journalctl -u psi-api -n 200 --no-pager
```

查看 Nginx 状态：

```bash
systemctl status nginx
nginx -t
```

## 常用重启

```bash
systemctl restart psi-api
systemctl reload nginx
systemctl restart redis
systemctl restart mysqld
```

一般改后端 jar 后重启 `psi-api`，改 Nginx 配置后先 `nginx -t`，再 `systemctl reload nginx`。

## 数据库备份

建议上线后每天至少备份一次。

手动备份：

```bash
mkdir -p <BACKUP_DIR>
mysqldump -uroot <DB_NAME> > <BACKUP_DIR>/psi-$(date +%F-%H%M%S).sql
```

恢复前先确认目标库可以覆盖：

```bash
mysql -uroot <DB_NAME> < <BACKUP_DIR>/备份文件.sql
```

## 查看端口

```bash
ss -lntp
```

正常情况下：

```text
80：Nginx 对外访问
8080：Spring Boot，只监听 127.0.0.1
3306：MySQL，仅服务器内部使用
6379：Redis，仅服务器内部使用
```

## 常见问题

页面打不开：

```bash
systemctl status nginx
curl -I http://127.0.0.1/
```

如果服务器内能访问、本地浏览器不能访问，优先检查阿里云安全组 80 端口。

登录或接口失败：

```bash
systemctl status psi-api
journalctl -u psi-api -n 200 --no-pager
curl http://127.0.0.1:8080/actuator/health
```

数据库连接失败：

```bash
systemctl status mysqld
mysql -u<DB_USER> -p <DB_NAME>
```

Redis 连接失败：

```bash
systemctl status redis
redis-cli ping
```

## 发布检查

每次发布后检查：

```bash
curl -I http://<SERVER_HOST>/
curl http://127.0.0.1:8080/actuator/health
systemctl status psi-api --no-pager
systemctl status nginx --no-pager
```

然后用浏览器访问：

```text
http://<SERVER_HOST>
```

确认能打开页面、能登录、库存/销售/商品管理核心页面能访问。
