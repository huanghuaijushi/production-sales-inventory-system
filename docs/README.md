## 文档维护规则

- 新文档放在 `docs/` 下，文件名使用小写英文和短横线。
- 文档开头说明用途，正文尽量按“背景、流程、注意事项、检查项”组织。
- 涉及环境变量、端口、账号、证书、域名的内容，要区分开发、测试、生产。
- 临时地址不要写成长期配置，例如 `trycloudflare.com` 地址只作为示例或测试记录。
- 文档更新后同步更新本导航页。
