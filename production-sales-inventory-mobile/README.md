# 产销存移动端一期实施文档

## 1. 项目目标

为产销存系统新增一个基于 `uni-app + Vue 3 + TypeScript` 的移动端应用，优先面向安卓手机与安卓平板，第一期聚焦车间工人、仓管人员的高频现场操作，并复用现有 `Spring Boot` 后端接口能力。

第一期目标不是复刻 PC 管理后台，而是先完成一个可以在现场直接使用的移动操作闭环。

## 6. 登录功能设计

### 6.1 登录请求

请求地址：`/api/v1/auth/login`

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

### 6.2 登录成功后处理

- 保存 `accessToken`
- 保存 `tokenType`
- 保存过期时间 `expiresIn`
- 保存用户信息 `sysUser`
- 更新登录状态
- 跳转首页

### 6.3 应用启动时处理

- 读取本地 token
- 调用 `/api/v1/auth/status` 校验当前会话
- 如果有效，进入首页
- 如果失效，清空本地登录信息并回到登录页

### 6.4 退出登录处理

- 调用 `/api/v1/auth/logout`
- 无论接口是否成功，都清空本地 token 和用户信息
- 返回登录页
